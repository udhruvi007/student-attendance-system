# 🎓 Student Attendance Management System

A simple command-line based Student Attendance Management System built using Python.  
This project helps manage student records and track attendance efficiently using JSON file storage.

---

## ✨ Features

- ➕ Add new students
- 👀 View all students
- ✅ Mark attendance (Present/Absent)
- 📅 View attendance by date
- 📊 Generate attendance reports
- ⚠ Low attendance warning (<75%)
- 🗑 Delete student records
- 💾 Data stored using JSON files

---

## 🛠 Technologies Used

- Python 3
- JSON
- File Handling
- Datetime Module

## ▶ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/student-attendance-system.git
```

2. Open the project folder

3. Run the Python file

```bash
python attendance.py
```
